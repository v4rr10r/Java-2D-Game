# Java 2D Game

A small 2D Java game I created showcasing classic game development features.

## Features

- Custom **map creation**
- **Sprite-based** player and objects
- Interactive objects like doors, chests, and keys
- Sound effects and background music
- Collision detection and simple game physics

## Project Structure

my2dgame/
├─ main/ → main game code
├─ res/ → resources (images, maps, sounds, tiles)
├─ .idea/ → IntelliJ project files
├─ src/ → source code (entities, objects, tiles)


## How to Run

- Open the project in **IntelliJ IDEA**  
- Run `Main.java` from the IDE  
- Enjoy your game!

## Notes

- `.idea/` folder included for smooth IntelliJ setup  
- `out/` and compiled files are ignored
